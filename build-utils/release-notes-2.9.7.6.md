基于 PrusaSlicer 2.9.7 稳定版的三点测圆与复合剖切版。

- 反转任一剖切平面时只切换保留侧，打印平台和坐标轴留在当前视角。可通过「正视剖面」「等轴测」或手动旋转切换观察方向。
- 新安装或使用默认打印机预设时直接进入主界面。需要添加打印机或材料时，可从「配置 → 配置向导」手动打开。
- 缩短复合平面剖切的复选框标签，将说明放进悬停提示。
- GitHub 仓库更名为 PrusaSlicer-Measure-Section。

Windows x64 安装包支持从上一版本覆盖升级并保留用户预设。也可解压便携包并运行 prusa-slicer.exe。源码和 SHA256.txt 随版本发布。
